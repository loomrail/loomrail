# Loomrail 0.1.0-alpha.1

**Status:** release candidate; not published yet
**Date:** 2026-08-29
**Dist-tag:** `next`

This is the first installable pre-alpha checkpoint of Loomrail. It is intended for local dogfooding and early
technical evaluation, not production use.

## What is included

- a single `loomrail` launcher package for macOS and Windows;
- a loopback-only daemon, one-time browser bootstrap and local SQLite state;
- the English/Russian Workbench with the persisted delivery board and Task Cockpit;
- durable Discovery → Plan → Implement → Review → QA → Acceptance workflows, budgets, Human Requests, Decisions,
  evidence and owner acceptance;
- live Codex execution in a per-task Git worktree, change summaries and per-file diffs;
- a read-only Claude Code adapter for Discovery, Plan and Review;
- bundled synthetic fixtures and a documented full-route example.

## Known limitations

- This is a pre-alpha: data migrations and package upgrades have not yet completed a public compatibility cycle.
- Loomrail does not push, merge, deploy or publish repository changes.
- Claude Code is not on the write path yet.
- There is no desktop package, remote execution, cloud sync, plugin SDK or product BrowserDriver.
- Linux is best effort; macOS and Windows are the blocking release platforms.

## Install before publication

```bash
pnpm pack:release
npm install ./dist-release/loomrail-0.1.0-alpha.1.tgz
npx loomrail --port 4176
```

After publication, install the explicit pre-release tag with `npm install loomrail@next`. See the
[release guide](../RELEASE.md) and the [English](../guides/USER-GUIDE.md) or
[Russian](../guides/USER-GUIDE.ru.md) user guide for the complete route.
