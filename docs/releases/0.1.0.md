# Loomrail 0.1.0

**Status:** published Stable for macOS Apple Silicon

**Date:** 2026-09-11

**Dist-tag:** `latest` (`next` remains on `0.1.0-beta.1`)

**Release Support Target:** `MACOS_ARM64` (`darwin/arm64`)

## What is Stable

- Local authenticated Codex CLI `0.153.4` and Claude Code CLI `2.1.260` execute all six workflow stages on macOS
  Apple Silicon without provider API keys or separate API billing.
- IMPLEMENT receives only bounded, permission-checked workspace operations and owner-approved verification recipes
  through Loomrail's provider-neutral executor. QA is read-only.
- Workflow state, permissions, budgets, gates, audit, Browser QA and Acceptance remain deterministic, domain-owned
  and durable across restarts.
- The private Recurkit Epic completed with both providers, a real failed-verification/correction loop, cross-provider
  Review, measured QA and owner Acceptance.
- Guided activation, diagnostics, backup/restore guidance, redacted logs, private Insights, dependency policy,
  release receipts and clean-package verification are included.

## Explicit platform boundary

Stable applies only to `MACOS_ARM64`. Windows source, browser, process-lifecycle and clean-package CI remains
mandatory and green, but real Windows Codex/Claude execution has not been captured. Windows and Linux live-provider
dispatch therefore fails closed and this release claims no support for them. There is no Mock, direct OpenAI/
Anthropic API route, token credential or synthetic fallback.

## Safety and limitations

- A worktree is collision isolation, not an operating-system sandbox. Providers run as the local user and receive
  network permission only when the exact run policy grants it.
- Provider token usage is `POST_SESSION`: time, turns, tool calls and output are bounded, while an individual provider
  turn can exceed its token estimate before terminal usage arrives.
- Loomrail never automatically commits, pushes, merges, deploys, updates itself or accepts delivery.
- Desktop packaging, remote access, cloud sync, team accounts and Windows/Linux live-provider support are not
  included.
- Database migrations are forward-only. Back up the full Loomrail data directory before upgrading.

## Install after publication

Use a new empty directory on macOS Apple Silicon:

```bash
mkdir loomrail-evaluation
cd loomrail-evaluation
npm install --ignore-scripts loomrail@latest
npx playwright install chromium
npx loomrail try
```

Sign in first with `codex login` or `claude auth login`. Loomrail reads only readiness facts and never asks for the
provider credential.
