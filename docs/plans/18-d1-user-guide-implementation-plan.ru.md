# D1 — Пользовательский гайд: план реализации

**Спецификация:** [`17-d1-user-guide-spec.ru.md`](17-d1-user-guide-spec.ru.md)

**Статус:** complete, изменения не закоммичены

**Объём:** документация и точечное исправление устаревшей UI-копии; новых runtime-возможностей нет.

## Ограничения

- Не редактировать конкурентную карту и утверждённую декомпозицию, которые уже меняются в рабочем дереве.
- Не обещать npm publish, desktop shell, remote mode, online export/restore или Git-authority.
- Английский гайд — основной публичный; русский повторяет тот же маршрут, но не обязан быть построчным переводом.
- Команды должны работать в macOS shell и Windows PowerShell либо явно называть платформу.
- Состояние нельзя предлагать копировать по одному live-файлу SQLite; WAL делает такую инструкцию небезопасной.
- Не коммитить и не push-ить без прямого разрешения владельца.
